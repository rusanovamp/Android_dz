DZ_1_COMPOSE — реализация на Jetpack Compose с использованием Row, Box и LazyVerticalGrid.
DZ_1_Views — реализация на XML с использованием LinearLayout и TextView.
DZ_1_RecyclerView — реализация с использованием RecyclerView, GridLayoutManager и Adapter.

Все три приложения отображают девять чисел в виде сетки 3 × 3 с заголовком «Числа».
